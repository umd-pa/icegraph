class icegraph.geometry.Detector

Bases: object

Handles detector-level information, such as accessing DOM coordinates from the GCD geometry using a provided configuration.

This class loads the I3Geometry frame from a GCD file and provides utility methods for retrieving DOM positions using string/OM/PMT info.

get_dom_coords(string, om, pmt)

Get the (x, y, z) coordinates of a DOM specified by string, OM, and PMT.

Parameters:

  • string (int) – The string number of the DOM.

  • om (int) – The optical module (OM) number.

  • pmt (int) – The PMT index (0 for standard DOMs, >=0 for mDOMs or IceCube Upgrade).

Returns:
