class icegraph.data.base.IGData(infile)

Bases: Dataset, ABC

The base dataset class for loading and managing IceCube data stored in LMDB format.

This class handles the truth table, feature loading, and optional selection filtering for training, validation, or test subsets. Subclasses must set the class attribute subset to one of: “train”, “validation”, or “test”.
