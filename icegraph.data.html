class icegraph.data.registry.DatasetRegistry(train_dataset, validation_dataset, test_dataset)

Bases: object

A container class for managing access to training, validation, and test datasets.

This class handles loading and conversion of raw input data into feature-ready Parquet format, applies caching, and wraps the resulting dataset objects for convenient access.

Dataset class for the test split.

Inherits from IGData and sets the required class attribute subset = “test”, which triggers filtering of the truth table to only include test events.
