class icegraph.trainer.module.GravNet(in_channels, hidden_channels, out_channels, layers=2)

Bases: Module

GravNet model for graph-level predictions.

The network applies successive GravNet convolutional layers to learn node embeddings, each followed by a linear transformation and ReLU activation. Finally, it aggregates node embeddings with global mean pooling and computes graph-level outputs via a final linear layer.

Parameters:

  • in_channels (int) – Number of input features per node.

  • out_channels (int) – Dimension of the final graph-level output.
