icegraph.utils.networking.is_port_available(port, host='127.0.0.1')

Check if a port is available on the given host.

Parameters:

  • port (int) – Port number to check.

  • host (str) – Host to bind to. Defaults to localhost “127.0.0.1”.

Returns:

True if the port is available, False if it’s in use.

Return type:

bool
