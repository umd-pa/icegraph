class icegraph.data.writers.LMDBWriter(outfile, mode='w', map_size=10737418240)

Bases: IGWriter

Serializes a pandas DataFrame to LMDB format for efficient key-value storage.

This class writes each row of the DataFrame as a serialized MessagePack object, using a consistent 8-byte key scheme to ensure deterministic and sortable entries.
