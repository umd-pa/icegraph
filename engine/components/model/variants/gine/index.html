GINE

Model variant implementing a graph isomorphism network with edge features (GINE) for graph-level prediction. Each layer adds a projection of the edge attributes to the neighbouring node features, sums the result over the neighbours of each node, adds the node’s own features scaled by 1 + eps, and passes the sum through a two layer MLP and an activation. The final node features are mean-pooled per graph and projected to the output width.

Configuration

Selected as name: gine.

Default

Number of GINE convolution layers.

Width of the edge attributes produced by the edge builder.

Learn eps in each layer instead of fixing it at 0.

checkpoint

Recompute each layer during the backward pass instead of storing its activations. Each layer stores a tensor of size edges by channels, so this cuts training memory by a large factor at the cost of roughly one extra forward pass. Only applies in training.
