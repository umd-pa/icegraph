GravNet

Model variant implementing the GravNet architecture for graph-level prediction. Each block learns a low-dimensional latent space, connects each node to its nearest neighbors in that space, and aggregates features over those learned neighbors. Final node features are mean-pooled per graph and projected to the output width.

See: Learning representations of irregular particle-detector geometry with distance-weighted graph networks
